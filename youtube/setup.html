YouTube digest setup

  1. Install or update the companion extension from the digest page. In its extension options, configure your DeepSeek key.
  2. In Google Cloud Console, enable YouTube Data API v3. Configure the OAuth consent screen. If the app is in Testing, add your Google account as a test user.
  3. Create an OAuth client of type Web application. Add https://yildirimozen.com under Authorized JavaScript origins.
  4. Copy the public client ID into the digest’s connection settings and click Connect YouTube. Read and approve the Google consent screen.

The page requests read-only YouTube access for your subscriptions and search. The access token lives in the current page and goes directly to Google’s API. DeepSeek receives the search text and candidate public YouTube titles and descriptions to classify results. The OAuth client ID and time used today are saved in this browser profile.

Limits reset at midnight in Zurich. Time counts while the player is open, and closing the player or leaving the tab stops it. These limits apply within this browser profile. The official YouTube player uses youtube-nocookie.com and needs access to YouTube’s media servers.
